# 建档初代卡（BUGFIX-07，封卡日 2026-11-22，当天禁止改口）

## 一句话

建档必须同时落下初代：容量与 `generation=1` 在同一条档期行里写入，要么全成、要么同滚。

## 选定路径：甲（同事务写容量并把代数置一写入档期行）

- 写口：`POST /api/slots`（`backend/slots_svc.py::create_slot`）。
- 单条 `INSERT INTO slots(..., capacity, booked, status, generation) VALUES (..., 1)`。
- 同一个 `connect()` 事务内完成：档期行 + 初代 + 审计。
- 任一步失败：不提交，档期行与代数同滚（走 `conn.rollback()`），库里零增。
- 禁止只展示容量：接口与页面必须同时可见 `generation`。

## 明确不采用：乙（初代影子原子切换）

- 不写影子行、不做影子→主行切换；两边不得混用。
- 当天若有人提乙路径，按偏离处置：拒写并记偏（`audit_trail.action='deviation_reject'`）。

## 正确性口径（唯一判据）

| 检查 | 口径 |
|------|------|
| 建档后读档期 | `generation == 1` |
| 占位可挂代 | `POST /api/holds` 返回 `generation == 1` |
| 确认快照 | `snapshot_gen == 1` |
| 失败回滚 | 建档失败后 `slots` 无该行、代数零增 |

## 锁与争用

- 建档先占 `slot:<code>` 档锁；两人同时建同名档，后到只记 `contention_log`（`action='争用'`），不写业务。
- 争用记录必须在失败返回前独立提交，不得被业务回滚带走。

## 同态五处

1. 档期页（档期盘）：显示 `代` 列，空代显示为「缺代」并标红。
2. 代数列：`generation` 统一 `int(... or 0)` 归一化。
3. 可挂代占位：占位接口回 `generation`，占位单显示携带的代。
4. 对账页：返回并显示 `generation`，空代计入非同源。
5. 审计页：建档/占位/确认审计载荷带 `gen`，偏离记 `deviation_reject`。
